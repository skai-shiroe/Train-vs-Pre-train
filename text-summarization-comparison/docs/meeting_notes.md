# Notes de Réunion

Ce document contient les notes de toutes les réunions du projet.

## Format

Pour chaque réunion, documenter :
- **Date** : JJ/MM/AAAA
- **Participants** : Noms
- **Ordre du jour** : Points discutés
- **Décisions** : Décisions prises
- **Action items** : Tâches à faire
- **Questions ouvertes** : Points à clarifier
- **Prochaine réunion** : Date et objectifs
