# Dossier Documentation

Ce dossier contient toute la documentation du projet de recherche.

## Structure

```
docs/
├── architecture.md      # Architecture technique du projet
├── project_plan.md      # Plan de projet et milestones
├── experiments.md       # Documentation des expériences
└── meeting_notes.md     # Notes de réunion et décisions
```

## Description des fichiers

### architecture.md
Documentation technique complète :
- Architecture des modèles (Transformer et T5)
- Flux de données
- Structure du code
- Dépendances et technologies utilisées
- Schémas d'architecture

### project_plan.md
Plan de projet détaillé :
- Objectifs et livrables
- Timeline et milestones
- Tâches par semaine
- Ressources nécessaires
- Risques et mitigation

### experiments.md
Documentation des expériences :
- Liste des expériences planifiées
- Protocoles expérimentaux
- Hyperparamètres testés
- Résultats et analyses
- Comparaisons entre modèles

### meeting_notes.md
Notes de réunion :
- Décisions prises
- Action items
- Questions ouvertes
- Prochaines étapes
- Feedback et reviews

## Conventions

- Utiliser Markdown pour tous les fichiers
- Mettre à jour régulièrement
- Dater les modifications importantes
- Lier vers les notebooks et résultats correspondants
