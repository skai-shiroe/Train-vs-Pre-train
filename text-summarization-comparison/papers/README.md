# Dossier Papers

Ce dossier contient les articles scientifiques de référence pour le projet.

## Objectif

Déposer ici tous les articles scientifiques utilisés comme référence pour le projet de Master en NLP.

## Articles à déposer

### Articles principaux (obligatoires)

1. **Attention Is All You Need** (2017)
   - Auteurs: Vaswani et al.
   - Citation: https://arxiv.org/abs/1706.03762
   - Rôle: Architecture Transformer de base

2. **Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer (T5)** (2020)
   - Auteurs: Raffel et al.
   - Citation: https://arxiv.org/abs/1910.10683
   - Rôle: Modèle T5 pré-entraîné

### Articles complémentaires (recommandés)

3. **BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension** (2020)
   - Auteurs: Lewis et al.
   - Citation: https://arxiv.org/abs/1910.13461

4. **PEGASUS: Pre-training with Extracted Gap-sentences for Abstractive Summarization** (2020)
   - Auteurs: Zhang et al.
   - Citation: https://arxiv.org/abs/1912.08777

5. **ROUGE: A Package for Automatic Evaluation of Summaries** (2004)
   - Auteurs: Lin
   - Citation: https://aclanthology.org/W04-1013/
   - Rôle: Métrique d'évaluation

6. **BLEU: a Method for Automatic Evaluation of Machine Translation** (2002)
   - Auteurs: Papineni et al.
   - Citation: https://aclanthology.org/P02-1040.pdf
   - Rôle: Métrique d'évaluation
